## 0. 先看清三个现实约束

### 约束一：你的显卡是 RTX 3060 Laptop **6GB 显存**

这是全程最大的限制。6GB 能干什么、不能干什么，先背下来，避免把时间浪费在"跑不起来的实验"上：

| 任务 | 6GB 本机可行性 | 说明 |
|---|---|---|
| nanoGPT 124M 从头预训练 | ✅ 可以 | `batch=8~16` + 梯度累积 + bf16，跑几小时能看到 loss 明显下降 |
| 0.5B 模型 LoRA 微调 | ✅ 可以 | `batch=1~2` + 梯度累积 + 梯度检查点 |
| 1.5B 模型 QLoRA(4bit) 微调 | ✅ 可以 | 序列长度 ≤ 512，容易 OOM，要耐心调 |
| 3B 模型 QLoRA(4bit) | ⚠️ 很勉强 | 需要 `seq=256` + 各种省显存开关，不保证成功 |
| 7B 模型 QLoRA(4bit) | ❌ 本机不现实 | 直接租云卡，别硬刚 |
| GRPO/PPO 强化学习训练 | ⚠️ 只能做 toy | 0.5B + 小 batch + 短 completion 勉强能跑通流程 |
| 正式 RLHF/GRPO 实验 | ❌ 必须租卡 | 这是本路线唯一"必须花钱"的地方 |

### 约束二：你必须租卡，但花不了多少钱

- **优先顺序**：实验室服务器（免费，第一周就去问导师/师兄要账号）> 云租卡 > 本机硬撑。
- **租卡成本**：4090 24G 约 2 元/小时（以当时实际价格为准）。本路线全程预计租 **60-100 小时，合计 150-250 元**。
- **用法**：平时在本机写代码+调试小实验，攒到周末集中租 8-10 小时跑正式实验。**租卡前先在纸上把脚本写好、把数据路径确认好**，上机只跑不写。
- 另外：6GB 卡上 Windows 桌面本身会吃掉 0.5-1GB，真实可用约 5GB。训练前关掉浏览器和无关程序，加环境变量 `PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True`。

### 约束三：寒假只有 4-5 周，不是你的终点

大厂日常实习普遍希望实习生能待 3-6 个月。所以：

- 面试话术提前想好：**"寒假全职 + 开学后每周 2-3 天（能远程更好）"**。
- 寒假实习真正的价值是**跳板**：拿到一段经历后，2027 年 3-4 月的暑期实习才是主战场（也是研一最重要的机会）。
- 目标分档（简历按 A 档标准写，投递按 B 档铺开）：

| 档位 | 方向 | 本路线可行性 |
|---|---|---|
| A 档 | 后训练 / RL 算法 / 训练框架 | 冲刺，靠项目质量和面试表现 |
| B 档 | 推理工程 / 数据工程 / 评测 / 训练平台 | 主攻，可行性高，之后能内转 A 档 |
| C 档 | RAG / Agent / 微调应用 | 兜底，最容易拿 offer |

## 4. 6GB 显存生存指南

**省显存开关（抄下来直接用）**

```python
# 环境变量
PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True

# 训练配置
per_device_train_batch_size=1        # 从 1 开始试
gradient_accumulation_steps=8~32     # 用累积凑出等效 batch size
gradient_checkpointing=True          # 用时间换显存，省 40-60% 激活显存
bf16=True                            # 优先 bf16，不要 fp16
optim="paged_adamw_8bit"             # bitsandbytes，省优化器状态显存
max_seq_length=512                   # 6GB 上别超过 1024
load_in_4bit=True                    # QLoRA
```

**其他技巧**

- 训练前关掉浏览器、微信、IDE 的无关窗口；Windows 桌面本身会占用 0.5-1GB 显存。
- 每次改配置后用 `nvidia-smi -l 1` 盯着显存看，OOM 时先减 `max_seq_length`，再减 batch。
- 笔记本散热很重要：垫高机身、清理风扇、必要时用 MSI Afterburner 或厂商工具限制功耗，温度过高会自动降频导致训练奇慢。
- **长时间训练别用 Jupyter**，用 `python train.py > log.txt 2>&1` + `nohup`/`tmux`，防止笔记本休眠中断。Windows 里记得把电源模式设为"高性能"、关闭休眠。
- 数据集先用小样本（1k-10k 条）跑通流程，再放大。

**租卡检查清单（上机前必须做完）**

- [ ] 脚本已在本地用小数据跑通，没有语法错误和路径错误
- [ ] 数据已上传或能自动下载，且确认过下载速度
- [ ] 训练参数已按目标卡（24G）调好，不再需要反复试错
- [ ] 日志和 checkpoint 路径已配置，checkpoint 会定期保存
- [ ] 预算上限心里有数（比如这次最多跑 10 小时）
- [ ] 跑之前先看一次 `nvidia-smi` 确认卡是空闲的
