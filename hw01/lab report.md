# HW01 实验报告：COVID-19 病例数预测

## 1. 数据理解
- 2699 行 × 118 列
- 结构：1 列 id + 37 列州 one-hot + 5 天 ×（15 个调查特征 + 1 个 tested_positive）
- 标签：tested_positive.4（第 5 天）

## 2. 基线
原始特征 + lr=1e-5 + 无标准化 → valid MSE = 3.41471

## 3. 实验记录
| # | 改动 | valid MSE | 相对基线 |
|---|---|---|---|
| 1 | 特征标准化 + lr=1e-3 | 1.03664 | -70% |
| 2 | 去掉 id | 0.90819 | -12% |
| 3 | 只用 4 天 tested_positive | 1.06258 | -69% |
| 4 | + 37 个州 | 1.14763 | -66% |
| 5 | 全部去 id | 0.90819 | -73% |
| 6 | Dropout 0.2 | 1.19705 | -65% |
| 7 | weight_decay 1e-2 | 0.90722 | -73% |
| 8 | 加宽模型 64/16 | 0.93811 | -73% |

## 4. 三条结论
1. **特征尺度决定学习率**：标准化让特征从几百降到 1，
   最优 lr 从 1e-5 移到 1e-3（移动了 100 倍）。
   不改 lr 只做标准化，loss 反而从 3.41 涨到 9.91。

2. **信号主要在 tested_positive 的历史里**：
   只用 4 个特征就能到 1.06；加入 75 个调查特征后到 0.96；
   但州 one-hot 单独加进去反而变差（1.06 → 1.15），
   说明 37 个 one-hot 在特征少时会主导输入、导致过拟合。

3. **正则化在这个任务上收益有限**：
   网络只有 16/8 个隐藏单元，dropout 20% 相当于砍掉 1.6 个神经元，
   直接把 train loss 推到 3.7（欠拟合）；
   weight_decay 在 lr=1e-3 下需要 0.1 以上才有效果。
   early stopping 已经是主要的正则手段。

## 5. 最终配置与结果
见上表第 5 行：116 特征 + lr=1e-3 + 无正则 → valid MSE = 0.90819
